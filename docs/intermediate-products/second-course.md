## 3️⃣ Markdown vs HTML 어느 것이 좋은가? (교육 시간: 10분 내외)

- LLM이 생성하는 산출물을 어떤 형식으로 쓰는 것이 좋은가?
- 토론: 마크다운 vs HTML

> 개인적인 생각 :
> - Markdown 문서는 LLM과 사람이 동시에 보기 좋은 문서라고 생각
> - 산출물 추적에는 Markdown 문서가 더욱 뛰어나다고 생각
> - Obsidian이라는 도구가 따로 있는데, 마크다운을 기본으로 하는 노트 필기 앱으로, LLM이 최소한으로 관여하는 문서 작업에는 안성맞춤이라고 봄
> - LLM이 생성한 산출물의 범위가 많을 경우, 사람이 일일이 다 보기에는 시간적으로 부족할 뿐만 아니라, 집중력도 떨어뜨리기 때문에, 간단한 HTML 파일을 통한 보고용으로 쓰는 것이 최선이라고 생각

- HTML 보고용 파일을 어떻게 구성해서 받으면 좋은가?

> 개인적으로 썻던 방식 :
> 1. LLM이 작업한 파일 목록을 요약하여 리스트업
> 2. 작업의 핵심 키워드를 뽑아 한 번 더 요약 (말뭉치 느낌?)
> 3. 이번 작업한 핵심 내용을 3줄 이내로 요약해서 HTML 파일의 히어로 섹션으로 구성
> 4. 핵심 키워드를 그룹으로 묶어 카드 형식으로 그리드화
> 5. 작업으로 인해 추가/수정/삭제된 파일들을 아래에 리스트화
> 6. 실무자가 한눈에 파악할 수 있도록 시각적으로 구성하는 것이 핵심
