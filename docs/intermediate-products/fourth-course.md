## 3️⃣ LLM 에이전트(Agent)에 대한 이해 (교육 시간: 20분 내외)

- Autonomous Agent란?
- Agent 내부 구조
    1. 자연어 이해
    2. 결정 및 계획 수립
    3. 행동 수행
    4. 학습 및 적응
- Agent 주요 구성 요소
    - 도구(Tool)
    - 기억(Memory)
    - 계획(Planning)
    - 행동(Action)
- Agent 동작 방식
    1. 사용자 입력
    2. 기억 - 과거 데이터 참조
    3. 계획 - 목표 달성 과정(단계) 구체화
    4. 행동 - 실제 작업 수행
    5. 반성 및 자기 비판 - 각 단계별 평가 및 개선
    6. 사고 연결 + 하위 목표 분해
