---

> 🎞️ 준회원 대상 **IDE 설정 가이드라인 PPT**를 Canva로 제작하는 절차를 기록한 문서입니다.

본 문서는 `docs/IDE-Setting-Guideline.md`의 내용을 발표 자료로 옮기는 과정을 정리합니다.  
작업은 사람과 AI가 번갈아 수행하므로, 각 단계의 담당자와 산출물을 명확히 구분합니다.  
작업이 중단되더라도 본 문서만 보면 이어서 진행할 수 있도록 작성했습니다.

# 2. 전체 작업 절차

## 가. 단계 요약

| 단계 | 담당 | 작업 내용 | 산출물 |
| :---: | :---: | :--- | :--- |
| 1 | 사람 | Canva에서 템플릿 페이지 복제 | 25페이지 빈 슬라이드 |
| 2 | AI | 25장 전체 텍스트 작성 및 순서 정렬 | 텍스트 완성본 |
| 3 | 사람 | 설치 화면 캡처 후 Canva 업로드 | 스크린샷 21컷 |
| 4 | AI | 업로드 애셋을 슬라이드에 배치 | 최종 완성본 |
| 5 | 사람 | 최종 검토 및 PPTX 내보내기 | 배포용 파일 |

## 나. 단계별 유의 사항

### 1) 페이지 복제 단계

- 복제 순서는 맞추지 않아도 됩니다.
- 순서 정렬은 2단계에서 AI가 `reorder_page` 기능으로 처리합니다.
- 복제를 마친 뒤에는 Canva 편집 화면을 닫습니다.
- 편집 화면을 열어두면 AI 작업과 충돌할 수 있기 때문입니다.

### 2) 텍스트 작성 단계

- 원고는 `slide-script.md`에 먼저 작성한 뒤 Canva에 옮깁니다.
- 텍스트를 채운 후 이미지 자리는 비워 둡니다.
- 스크린샷이 없어도 이 단계까지는 완료할 수 있습니다.

### 3) 캡처 단계

- 파일명은 `01-git-download.png`처럼 **번호로 시작**하도록 짓습니다.
- 번호는 아래 5장의 캡처 목록과 일치시킵니다.
- 이메일 주소, API 키, 개인 파일 경로가 노출되지 않도록 확인합니다.

### 4) 이미지 배치 단계

- AI가 Canva 업로드 폴더의 애셋 목록을 읽어 자동으로 배치합니다.
- 배치 후 썸네일로 결과를 검증합니다.

# 4. 페이지 복제 지시표

## 가. 복제 방법

1. Canva 편집 화면에서 대상 페이지를 선택합니다.
2. 페이지 우상단의 `⋯` 버튼을 클릭합니다.
3. `페이지 복제`를 선택합니다. (단축키: `Ctrl + D`)

## 나. 복제 수량

| 현재 페이지 | 페이지 이름 | 작업 | 최종 수량 |
| :---: | :--- | :---: | :---: |
| 3 | 시장 분석 보고 | 2번 복제 | 3장 |
| 5 | 프로젝트 목표 | 8번 복제 | 9장 |
| 6 | 프로젝트 진행일정 | 3번 복제 | 4장 |
| 7 | 기술적 접근 | 1번 복제 | 2장 |
| 10 | 기대 효과 및 KPI | **삭제** | 0장 |
| 1·2·4·8·9·11·12 | 나머지 페이지 | 유지 | 각 1장 |

- 복제를 마치면 전체 **25페이지**가 됩니다.
- 10페이지(도넛 차트)는 설치 안내에 사용할 곳이 없어 삭제합니다.

# 6. 원고 작성 원칙

## 가. 문장 방식

- 세부 요소는 **개조식**으로 작성합니다.
- 서술형 문장 대신 `① 다운로드 페이지 접속` 형태를 사용합니다.
- 한 슬라이드의 글머리는 5줄 이내로 제한합니다.
- 한 문장은 20자 이내로 작성합니다.

## 나. 명령어 표기

- 명령어는 별도 박스에 단독으로 배치합니다.
- 운영체제별 명령어는 좌우로 나누어 제시합니다.

## 다. 원본 문서와의 차이

원본 문서와 PPT는 목적이 달라 일부 내용을 조정합니다.  
문서는 검색과 정독을 위한 자료이고, 슬라이드는 따라 하기 위한 자료이기 때문입니다.

| 구분 | 원본 문서 | PPT | 조정 사유 |
| :---: | :--- | :--- | :--- |
| Claude · Codex | 체크리스트에 "필수" 표기 | **"선택"으로 통일** | 본문 설명과 모순을 해소 |
| Antigravity CLI · SDK | 설치 절차 포함 | 소개만 수록 | 준회원 필수 범위가 아님 |
| Claude 앱 · ChatGPT 앱 | 미수록 | **신규 작성** | 앱 설치 안내 요청 반영 |
