## 실습: 자기소개 페이지 고도화 (토큰 절약형)

1차시 `my-intro/index.html`을 이어서 사용한다. 수강생이 Plus 요금제임을 고려해 토큰 사용을 최소화한다.

- 실습마다 프롬프트 1~2개, `index.html`의 한 부분만 수정
- 모든 프롬프트 끝에 "변경한 부분만 수정하고, 설명은 3줄 이내로." 추가
- 루프 실습은 최대 2회 반복으로 제한, 결과는 수강생이 브라우저로 직접 확인
- "토큰 아끼는 법" 슬라이드 1장 제공 (가벼운 모델 선택, 파일 통째로 붙여넣지 않기 등)

### [실습 1] 프롬프트 개선 (p16)

```
❌ 자기소개 페이지 예쁘게 바꿔줘

✅ 너는 웹 디자이너야. index.html의 자기소개 문단만 수정해줘.
- 관심사 3가지를 목록으로 정리
- 말투는 친근하게, 3문장 이내
- 다른 부분은 건드리지 말 것
```

### [실습 2] TCREI로 '올해 목표' 섹션 추가 (p27)

```
[Task] index.html에 '올해 목표' 섹션을 추가해줘.
[Context] HTML 파일 하나로 된 자기소개 페이지야. 외부 라이브러리는 쓰지 마.
[Reference] 기존 자기소개 섹션과 같은 글꼴·색상·여백을 따라해.
[Evaluate] 목표 3개가 카드로 보이고, 휴대폰 화면에서도 깨지지 않을 것.
[Iterate] 끝나면 내가 확인할 점 1가지만 알려줘.
```

### [실습 3] 하네스: AGENTS.md 규칙 파일 (p36)

```
프로젝트 폴더에 AGENTS.md를 만들고 아래 규칙을 적어줘.
1. index.html 한 파일만 수정한다
2. 색상은 파란색(#5170ff) 계열만 쓴다
3. 수정 후 변경 요약을 3줄로 남긴다
4. 모르면 추측하지 말고 질문한다
```

- 이어서 "배경을 빨간색으로 바꿔줘" 요청 → AI가 거절하거나 되묻는지 확인
- 강사 사전 확인: Antigravity가 `AGENTS.md`를 자동으로 읽는지 확인 (`.agent/rules/`만 읽으면 프롬프트 위치 수정)

### [실습 4] 루프: 5단계 한 번에 지시 (p40)

```
아래 순서로 작업해줘.
1. Discover: index.html을 읽고 개선할 점 2가지만 찾기
2. Plan: 계획을 3줄로 보여주고 내 승인 기다리기
3. Execute: 승인되면 수정
4. Verify: AGENTS.md 규칙을 지켰는지 스스로 점검
5. Iterate: 문제가 있으면 1번만 다시 고치고 멈추기
```
