## 확장한 교육 내용

### PART 01 미니 프로젝트 실습 (30분)

- 7차시 기획서(PLAN.md) 복습: 문제(누가·언제 불편?) → 핵심 기능 3개(MVP) → 화면 구성
- 주제: 신입 회원의 입장에서 동아리에 필요한 서비스 / 세부 주제 예시 6개
- MVP: 핵심 기능 하나가 동작하면 성공, 완벽보다 완성
- 개발 흐름 4단계: 기획서 전달 → 화면 만들기 → 기능 붙이기 → 확인·배포
- 프롬프트 3원칙 복습: 구체적으로 · 한 번에 하나씩 · 확인하고 고치기
- 실습 1~5: 프로젝트 시작(PLAN.md 읽히기) → 화면 프롬프트 → 기능 프롬프트(localStorage 저장) → PLAN.md 대비 점검 → Vercel 배포(선택)
- 자주 겪는 문제(흰 화면 · 고칠수록 망가짐 · 엉뚱한 결과), AI에게 도움 요청하는 법, 실습 체크리스트

### PART 02 결과 공유 · 발표 (20분)

- 발표 자료 흐름: Antigravity로 초안 → Markdown 정리 → Canva · PowerPoint로 디자인
- 발표 4요소: 문제·대상 / 해결·핵심 기능 / 시연·기술 스택 / 배운 점·다음 계획
- 1분 발표 슬라이드 4장 구성, Markdown 초안 프롬프트(PRESENTATION.md)
- Canva vs PowerPoint, 발표 팁 3가지, 예비 발표 진행 방식(1인 1분 + 질문 1개), 피드백 기준, 질의응답 주제

### PART 03 예비 교육운영진 모집 (20분)

- 교육운영진이란? 커리큘럼 기획 · 자료 제작 · 수업 진행
- 한 차시 준비 과정: 주제 조사 → 기획서 작성 → 자료 제작 → 수업·회고
- 노하우: 자료 준비(LLM 초안 + 직접 검증) · 전달 방식(비유 + 실습) · 자료 조사(1차 자료 + AI 요약)
- 느낀 점: 다른 운영진과의 소통, 나만의 장점(LLM 활용 자료 제작 시간 단축), 자기소개서 활용(크래프톤 · Infineon · SK Broadband 서류 합격), 지식 재정리
