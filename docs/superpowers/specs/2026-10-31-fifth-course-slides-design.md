## 실습 흐름 (Antigravity IDE 에이전트 + Gemini 무료 키)

1. Google AI Studio에서 API 키 발급 → 프로젝트 폴더의 `.env`에 `GOOGLE_API_KEY` 저장
2. [실습 1] 에이전트에게 Python 가상환경과 `langchain`, `langchain-google-genai` 설치 요청
3. [실습 2] LCEL 체인(`prompt | model | parser`) 한 개를 만들고 실행
4. [실습 3] 가상 쇼핑 리뷰 10개를 `reviews.txt`로 생성
5. [실습 4] 리뷰를 분할 → 임베딩 → 메모리 Vector Store에 저장 → 검색 + 답변하는 `rag.py`
6. [실습 5] 질문하고 근거 리뷰(출처)를 함께 출력, 리뷰에 없는 질문으로 환각 방지 확인
- 토큰 절약: 프롬프트 1~2개, 리뷰 10개, 검색 상위 3개로 제한
- 모델명은 프롬프트에서 "무료로 쓸 수 있는 Gemini Flash 계열"로 지정 (버전 변경에 대비)
