## 원칙

- 본문은 키워드·개조식만, 강의 설명은 발표자 노트에 작성

- 실습 코드·프롬프트는 어두운 둥근 박스 + 고정폭 글꼴의 코드 블록으로 표시

## 실습: 나만의 자기소개 페이지

1. 바탕화면에 폴더 생성 → Antigravity 2.0에서 프로젝트로 열기
2. 생성 프롬프트 입력 → `index.html` 생성
3. 파일 더블클릭 → 브라우저에서 확인
4. 후속 프롬프트로 수정 (배경색, 이모지, 버튼 알림) → IDE에서 변경 내용 확인
